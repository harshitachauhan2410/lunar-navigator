# Lunar Landing Navigator

A web tool that shows when the Sun and Earth are visible at a lunar site, ranks the best landing windows, and shows how sensitive they are to date and location.

Live demo: https://harshitachauhan2410.github.io/lunar-navigator/

## Limitations
Sun and Earth positions use an approximate model (about one degree). Terrain is a single horizon angle, not real elevation data.
